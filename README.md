# 📚 教務手帳 出欠管理Webアプリ

高校・小中学校の授業での欠課時数（出席状況）を、スマホやPCから簡単に記録・確認できるWebアプリケーションです。

非常勤講師の先生や、複数クラスを横断して授業を担当されている先生に最適です。

## 🌟 主な特徴

*   📱 **スマホ＆PC両対応**
    
    ブラウザで動くため、端末を問わずインストール不要ですぐに使えます。
    
*   🔑 **自分専用の独立データ（プライバシー安心）**
    
    アクセス時に自動で「自分専用の部屋（共有ID）」が生成されます。他の先生とデータが混ざる心配はありません。
    
*   🔄 **複数端末でのリアルタイム同期**
    
    教員のスマホと授業用PCに同じ「共有ID」を設定することで、どちらの端末から入力しても瞬時に同期されます。
    
*   📊 **履修不認定（単位修得）アラート表示**
    
    単位数に応じた欠課限界に近づくと、注意マーク（`❗️` や `‼️`）で自動警告します。
    
*   📁 **Excelからの生徒一括登録 ＆ CSV出力**
    
    名簿のテキスト貼り付け・Excelファイルの読み込みに対応。学年末処理や成績提出用データのCSV出力も可能です。
    

## 🚀 使い方ガイド（初めての方へ）

### 1. アプリを開く

管理者から案内された **URL**（または **QRコード**）をブラウザで開きます。

※初回アクセス時に、端末ごとに**自分専用の共有ID**が自動で作成されます。

### 2. スマホとPCでデータを同期させる方法（おすすめ）

授業中のスマホ入力と、職員室のPC入力を同期させたい場合：

1.  **PC**でアプリを開き、画面右下の **「共有ID」**（例: `room-a8b23c`）を確認します。
    
2.  **スマホ**でアプリを開き、ヘッダーの **「🔑 共有ID変更」** をタップします。
    
3.  PCと同じ文字列（`room-a8b23c`）を入力します。
    
4.  これで自分専用の2端末がリアルタイム同期されます。
    

### 3. クラスと科目の設定

1.  画面上の **「⚙️ クラス・科目設定」** をクリックします。
    
2.  クラス名（例: `1年1組`）、科目名（例: `英語コミュニケーションⅡ`）、単位数を設定して保存します。
    

### 4. 生徒名簿の登録

1.  画面上の **「👤 生徒編集（Excel読込）」** をクリックします。
    
2.  Excelファイルをドラッグ＆ドロップするか、「1 青木 一郎」のようにテキストエリアに貼り付けて保存します。
    

### 5. 日常の出欠記録

*   **一括追加**: 「欠課日時」を選択 ➔ 欠席した生徒のチェックボックスをオン ➔ **「＋ チェック生徒に追加」** を押します。
    
*   **個別追加**: 各生徒の右側にある **「今日を追加」** や **「手入力」** からもすぐに追加できます。
    

## 🔒 セキュリティ・データ管理について

*   データはクラウド上の独立した共有ID領域に保存されます。
    
*   共有ID（合言葉）を知っている端末同士のみがデータにアクセス可能です。自分だけのユニークなIDを使用してください。
    

## 💡 スマホのホーム画面に追加する方法（アプリ化）

*   **iPhone (Safari)**: 画面下の共有ボタン ➔ **「ホーム画面に追加」**
    
*   **Android (Chrome)**: 右上の3点メニュー ➔ **「ホーム画面に追加」**
    

ホーム画面からワンタップで起動できるようになり、より快適にご利用いただけます。

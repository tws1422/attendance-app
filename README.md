📚 教務手帳 for iPad
高校・小中学校の授業での欠課時数（出席状況）を、iPadやPCから簡単に記録・確認できる教員向けのWebアプリケーションです。非常勤の先生や、複数クラスを横断して授業を担当されている先生に最適です。

🌟 主な特徴
🔑 Google認証＆安心のプライバシー

指定ドメイン（@g.kagawa-edu.jp）の教職員アカウントでのみログイン可能。安全に自分専用のデータを管理できます。

🔄 自動リアルタイム同期

iPadとPCなど複数の端末で同じアカウントにログインすれば、どちらから入力しても瞬時にデータが同期されます。

⚠️ 欠課時数アラート（単位数に対応）

単位数に応じた上限（1単位＝12時間等）に近づくと、生徒の行の背景色が自動で変わってお知らせします。

欠課2以上：黄色

欠課7以上：薄い赤

欠課12以上（上限超過）：濃い赤

📊 カンタン名簿登録 ＆ CSV出力

Excelから「出席番号」と「氏名」の2列をコピーしてそのまま貼り付け可能（CSVファイルの読み込みやテンプレートDLにも対応）。成績提出等に便利なCSV出力機能も備えています。

↩️ 安心の操作履歴（Undo）

間違えて入力・削除してしまっても、「戻る」ボタンで一発で元に戻せます。

🚀 かんたん 3ステップの使い方
ログインする

「Googleでログイン」ボタンを押し、指定の教職員アカウントでサインインします。

クラスと生徒を登録する

新しいクラスを追加し、「クラス・科目設定」でクラス名や単位数を設定します。

「生徒編集・Excel貼付」から、Excelの名簿をコピー＆ペーストして一括登録します。

欠課を記録する

対象の日付を選び、欠席した生徒のチェックボックスをオンにして「選択生徒に日付追加」を押します（各生徒の「本日の欠課を追加」や過去日付の直接追加も可能です）。

📱 ホーム画面に追加してアプリのように使う方法
iPadやスマホのホーム画面にアイコンを追加すると、ブラウザのツールバーが消えて専用アプリのように全画面で快適に使えます。

iPad / iPhone (Safari)

画面下部（または上部）の共有ボタン（四角から矢印が出ているアイコン）をタップ

メニューから 「ホーム画面に追加」 を選択

Android (Chrome)

画面右上の「︙（メニュー）」をタップ

「ホーム画面に追加」 （または「アプリをインストール」）を選択

🔒 セキュリティ・データ管理について
データはクラウド上の安全なデータベースに保存され、本人以外のアクセスや混同はありません。

過去年度のデータは「閲覧専用モード」として自動保護され、誤って過去の記録を書き換えてしまう心配もありません（新年度へのデータ引き継ぎ機能も搭載）。
